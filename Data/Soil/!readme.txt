The raster was created from the soil100th3.shp file and the soilRastID field. It was aligned with the DTM5_v6.tif layer.
There is a relationship between the Value and soilRastID fields in the soil100th.tif raster and the lookup.csv file.
The data comes from Polish geodetic resources and the State Forests. It has been aggregated from various scales (5th-25th) to a scale of 100th.
